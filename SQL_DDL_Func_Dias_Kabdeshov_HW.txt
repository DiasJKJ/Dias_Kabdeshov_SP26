film_in_stock - inventory filtered by film_id and store_id and uses inventory_in_stock() to check if its in the shelf

rewards_report - Calculates a date range, start of month, 3 months ago. Then creates a temporary table and builds an INSERT string. After it executes to find customers meeting purchase/count thresholds. Their full profiles are returned

4) Which functions violate best practices?

inventory_in_stock has two counts. We can be fix it by using EXISTS instead of one of the counts
fixed:
CREATE FUNCTION inventory_in_stock(p_inventory_id INT) RETURNS BOOLEAN
READS SQL DATA
BEGIN
    DECLARE v_out_exists INT DEFAULT 0;

    -- Directly check if ANY active rental exists for this inventory item
    SELECT 1 INTO v_out_exists
    FROM rental 
    WHERE inventory_id = p_inventory_id 
      AND return_date IS NULL 
    LIMIT 1;

    IF v_out_exists = 1 THEN
        RETURN FALSE;
    ELSE
        RETURN TRUE;
    END IF;
END;

it didn't implement 3rd requirement "If a film is more than rental_duration * 2 overdue, charge the replacement_cost", so:
SUM(
  CASE
    WHEN (rental.return_date - rental.rental_date) > (film.rental_duration * 2 * INTERVAL '1 day')
      THEN film.replacement_cost
